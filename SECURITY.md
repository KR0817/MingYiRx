# Security and clinical privacy

Do not upload patient records, identifiers, linkage keys, private manifests, or
credentials to issues, pull requests, or the repository. Use synthetic examples
when reporting bugs. Keep real data outside the checkout and generated results
outside version control. Aggregate thresholds reduce some disclosure risks;
they do not guarantee anonymity across arbitrary table combinations.

Report vulnerabilities privately using GitHub private vulnerability reporting
when available, or contact the repository owner without including sensitive data.
This software is a research tool, not a clinical decision or prescribing service.
