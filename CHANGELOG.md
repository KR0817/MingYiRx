# Changelog

## 0.16.0 — First public MIT release

- Publish the current analysis library, CLI, synthetic examples, and tests.
- Include research dashboards, usage-ranked item controls, combination folding,
  focal co-prescription networks, figure export, terminology review, visit-gap
  sensitivity, and fixed-margin network reference utilities.
- Add `dashboard-sources` to switch complete approved aggregate dashboards,
  including annual trends, without mixing source denominators or guessing identity.
- Reject non-boolean `synthetic_mode` values; identify synthetic demonstrations
  visibly instead of labeling every input as real outpatient records.
- Make context loading configurable and workbook provenance explicit; declare
  the optional Excel dependency.

Clinical inputs, patient-level records, unpublished clinical dashboards, and
project-specific local automation are not included. A source match is not a
confirmed patient match. Prescribing patterns do not establish treatment effects.
